# مراجعة الاختبارات أثناء الفصل المعماري

لم تُستبدل القيم المرجعية بنتائج النسخة الجديدة. تبقى `baseline-transport.json` و`report-refactor-baseline.json` و`baseline-screen-text.json` ومراجع `tests/reference/domain` أدلة مستقلة.

| الاختبار | سبب التغيير | التغطية البديلة/المحفوظة |
|---|---|---|
| `resource-loading.test.ts` | حذف الموارد العامة ودمج ERP | صفحات HTTP كاملة، الإلغاء، اتساق النطاق والمراجعة، مفاتيح المستخدم/الدفتر/اللغة، آثار إبطال الفواتير. لم يعد اختبار دمج مجموعات عامة سلوكًا مطلوبًا. |
| `page-rendering.test.tsx` | حذف وصف الموارد و`legacyId` ومزود بيانات الميزات | الشاشات الأصلية عبر query options الحقيقية وHTTP DTO fixtures. بقيت النصوص المرجعية محفوظة. |
| لقطات إضافة/قائمة المستخدمين والجلسات | كان harness القديم لا يمرر المستخدم المصادق عليه، فظهرت رسالة منع المسؤول بدل النموذج والقائمة | تأكيد عناصر المسؤول والشكل الجديد، واختبارات browser للحفظ والتعديل وإعادة كلمة المرور والتعارض والمنع قبل HTTP. إضافة زر «إنهاء جلساتي الأخرى» في المقارنة تصحيح لحالة الاختبار، وليس تغيير صلاحيات الإنتاج. |
| `navigation.test.ts` | المسارات القديمة لم تعد معمارية مطلوبة | تحويل كل مسار أصلي عبر سجل URL changes، بقاء create/edit/deep links، عدم وجود الأسماء القديمة أو تكرار. |
| `transport-preservation.test.ts` | تغير مالك بعض الدوال وموضعها | اكتشاف مالك واحد لكل service مع نفس 41 توقعًا مستقلاً للطريقة والرابط وbody. |
| `business-rule-preservation.test.ts` | تغيرت التعليقات والأنواع الضخمة إلى عقود ضيقة | مقارنة AST التنفيذي مع المراجع الأصلية الثابتة مع استثناء annotations. `extras` له اختبار differential للإخراج وعدم تعديل الإدخال، لأن غياب products أصبح مسموحًا للإسقاطات الصغيرة. |
| `naming-contracts.test.ts` | نقل DTOs والتخلص من `SaveAuthActionRequest` العام | حقول DTO القديمة محفوظة عدا wrapper `action` الملغى، المسجل في `retiredExpected`. بديله `auth-transport.test.ts` لطلبات auth/users المحددة. |
| `policy-preservation.test.ts` | فصل validatePolicy حسب الأوامر | مقارنة القرارات والرسائل وعدم التعديل مع الأصل عبر المدخلات والحالات والسياسات المختلفة. |
| `refactor-boundaries.test.ts` | انتقال المكونات من core إلى shared | نفس ضمانات العزل على core/shared مع حفظ checksums المراجع. |
| `architecture.test.ts` | السماح بطبقات feature المطلوبة ومنها mappers | منع الديمو وWorkspace، الأنواع المنفصلة وغياب any، مع فحص اعتمادات AST مستقل يُنفَّذ في CI. |
| HTTP backend الخاص بالمتصفح | الرد العام `{ok:true}` يخفي فشل المستخدمين والجلسات | حفظ حالة المستخدمين والجلسات، رفض المدخلات والتكرار والصلاحيات، وحقن فشل محدد لاختبار الواجهة. تبقى هذه محاكاة عقد وليست إثبات backend حقيقي. |

تثبيت تاريخ seed على `2026-10-31T12:00:00Z` يعيد نفس ظروف الالتقاط الأصلي دون تغيير النتائج المتوقعة. تستخدم اختبارات المتصفح الأسماء المتاحة فعليًا؛ `Field` يحذف علامة النجمة من `aria-label` ويحتفظ بـ required.
